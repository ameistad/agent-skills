# Rewrite Examples

Use these examples to calibrate edit depth and output shape. Match the source text rather than copying the examples' tone.

## Professional message

### Input

> I hope this message finds you well. I just wanted to reach out and let you know that we have made the difficult decision to move forward with postponing the launch until next week in order to ensure that everything is fully ready.

### Revised Text

> We've postponed the launch until next week to make sure it's ready.

### Suggestions

- Add the new launch date if it is confirmed.
- Name the remaining work if the audience needs to understand the delay.

## Product copy

### Input

> Our cutting-edge platform seamlessly empowers teams to leverage powerful collaboration capabilities and unlock unprecedented productivity.

### Revised Text

> Our platform helps teams collaborate and get work done more efficiently.

### Suggestions

- Replace the productivity claim with a customer result or measured outcome if one is available.

## Over-structured prose

### Input

> There are three key reasons to adopt this approach. First, it enhances clarity. Second, it facilitates collaboration. Third, it drives alignment. Ultimately, these benefits underscore why the approach is so valuable.

### Revised Text

> This approach makes the work clearer, helps people collaborate, and keeps the team aligned.

### Suggestions

- Add one concrete example showing where the current approach creates confusion or slows collaboration.

## Technical instructions with protected content

### Input

> In the event that you encounter the `E_CONN_14` error, it is recommended that you navigate to Settings > Network and subsequently execute `app repair --network` from `/opt/acme/bin`.

### Revised Text

> If you see `E_CONN_14`, open `Settings > Network`. Then run `app repair --network` from `/opt/acme/bin`.

### Suggestions

- State whether users need administrator access to run the command.

## Already-natural writing

### Input

> We tried the new onboarding flow with six customers. Four finished without help; two got stuck at the permissions screen. I think we should fix that screen before we invite the next group.

### Revised Text

> We tried the new onboarding flow with six customers. Four finished without help; two got stuck at the permissions screen. I think we should fix that screen before inviting the next group.

### Suggestions

- No further changes are needed unless the audience needs details about the permissions issue.

## Non-English text

### Input

> Vi ønsker med dette å informere om at vi har tatt beslutningen om å utsette lanseringen til neste uke, slik at vi kan sikre at alle nødvendige elementer er på plass.

### Revised Text

> Vi utsetter lanseringen til neste uke for å få alt på plass.

### Suggestions

- Legg til den nye lanseringsdatoen hvis den er bestemt.
- Nevn hva som gjenstår hvis mottakerne trenger å forstå forsinkelsen.
